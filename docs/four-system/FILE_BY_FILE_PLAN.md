# Exact additive implementation plan

This is a proposal. No bridge, inference adapter or TradingAgents service is implemented by this audit. Every destination below is new; no native upstream file is patched. Separate distributions avoid a top-level `tradingagents` name collision and preserve all original environments.

Dependency order: B0 packaging → B1 identities/contracts/ledger → B2 approved Zenith inference → B3 Hermes + B4 OpenClaw → B5 native TradingAgents service/support/report delivery → B6 cross-system acceptance → B7 supervised deployment. Tests land with each implementation, not only at the end.

The existing `integrations/runtime_setup` remains independent. The earlier 63-file bridge proposal is historical; these exact destinations extend it with a namespaced bridge and native TradingAgents service. The existing Zenith `agent/` code and native state are not replaced.
