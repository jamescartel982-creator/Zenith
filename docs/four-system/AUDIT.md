## Existing integration reality

Only `integrations/runtime_setup` exists: it installs independent Node/Python/test SDK prerequisites. Zenith's `/api/chat` and `/api/chat/stream` are application/agent APIs; they must not be relabelled raw model endpoints or routed recursively through native agents.

Hermes and OpenClaw remain preserved independent source trees. Their full native dependency environments and complete native suites have not been verified here; runtime/test SDK installation is not native operation. TradingAgents is now a fourth separately pinned source, not a fourth connected running service. No trading, brokerage, public service or messaging delivery has been enabled.

## Compatibility and gates

Use TradingAgents' existing `openai_compatible` provider, not `openai` or an invented service endpoint. Configure `quick_think_llm` and `deep_think_llm` to the verified Zenith alias and both tier providers/endpoints explicitly; `OPENAI_COMPATIBLE_API_KEY` carries a dedicated local service credential. Never embed it in config examples or model context. Graph tools and structured managers require real tool-call and schema compatibility tests; a text-only proxy is insufficient. The current small Zenith checkpoint has not demonstrated that complete financial workflow.

The default native graph is preserved: all analysts → bull/bear → research manager → trader → all three risk debaters → portfolio manager → native rating/log/reports. Hermes findings are supporting evidence and never substitute for native portfolio risk review. OpenClaw delivery must use its native `send` RPC (paired/scoped Gateway v4), with explicit report-hash/recipient approval. `chat.send` submits an agent turn; it is not a report delivery API.

Native point-in-time guards clamp tool dates, withhold present-day snapshots, filter dated news/social/SEC statements and prevent future outcomes entering memory. Native settlement enters at the first close after the decision date. Tests cover these contracts. However native backtest text explicitly says text feeds are not archived and results are not fully repeatable. These guards do not erase future facts from model weights; Zenith's complete financial training-knowledge cutoff is not verified. Do not label a historical run universally leakage-free or fabricate data provenance/calibrated confidence.

The native backtester explicitly has no fill prices, quantities or cash ledger. Paper execution is a separate proposed extension with its own ledger and fees/slippage model. No live broker adapter or order endpoint is proposed; live mode must fail closed, without broker credentials or broker egress, including in supporting agent profiles.

## Independent MacBook and presentation work

A concrete installer bug is verified: the current CPU path sends macOS to the Linux/Windows PyTorch CPU wheel index. Apple Silicon must use the standard PyPI macOS wheel. Current PyTorch 2.14.1 publishes `macosx_14_0_arm64` wheels and no Intel macOS wheel. Keep the secure Torch floor; do not downgrade Intel users to unmaintained 2.2.2 or silently change their model. Native Apple Silicon installation and original-checkpoint inference need macOS CI; Intel supports the core app with an explicitly chosen external backend, not native HF inference. MPS is optional and physical-GPU validation remains separate.
